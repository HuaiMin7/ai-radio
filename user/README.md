# User Profile

This folder contains the personal context used by the AI DJ.

- `taste.md` describes musical taste and preferences.
- `routines.md` describes daily routines and listening situations.
- `playlists.json` contains structured taste samples used to infer the user's listening profile. It is not a recommendation boundary or playback queue. Each track can include title, artist, NetEase search keyword, mood tags, scene tags, energy, vocal/language metadata, and a DJ angle for narration.
- `mood-rules.md` maps mood, time, and context to radio behavior.
